        Sector Correlation

        How closely each sector's daily moves have tracked each other over the last 60 trading days. Darker/warmer = more correlated (they tend to move together); cooler = more independent. Low-correlation pairs are where rotation between sectors is most visible.

        Momentum vs. Mean-Reversion

        For each sector, the correlation between one non-overlapping weekly return and the next, using whatever history has synced so far. Positive = weeks tend to keep going the same direction; negative = weeks tend to reverse. "Notable" only flags values outside roughly 2 standard errors of pure noise — this is a diagnostic on this sector's own history, not a forecast.

        Seasonality Calendar

        Average historical return by calendar month, based on whatever history has been synced so far — with limited years of data this is directional, not statistically robust.

        Sector Detail

        Ranked by weekly performance. Score (0–100) blends 1D/1W/1M performance and momentum, each ranked against today's other 10 sectors — 50 is average, not a fixed benchmark. Click a column header to re-sort.
